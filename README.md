# Harmonia

Web app de aprendizado musical (React + Vite + Tailwind CSS).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera /dist
```

Rotas (hash): `#home`, `#import`, `#song`, `#learn`, `#assistant`.
Importador e assistente são simulados. Veja os comentários em `pages/Importer.jsx` e `components/chat/Assistant.jsx` para ligar APIs reais.
